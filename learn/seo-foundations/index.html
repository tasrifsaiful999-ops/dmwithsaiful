SEO Foundations

The core ideas behind helping the right people find your website.

By Saiful Islam Mollah, Digital Marketing Specialist · October 12, 2026

What SEO is

Search engine optimisation is the work of making your website easier for search engines to understand and more useful for people searching. Results are not guaranteed and depend on many factors.

Start with search intent

Ask what someone typing a query actually wants. Match each page to one main topic. Example: a page about bridal jewellery should answer what a bridal jewellery shopper needs to know.

Keyword mapping

List the phrases your customers use and assign each to a single page, so pages do not compete with each other.

On-page basics

Give each page a unique title, a clear description, a single main heading, descriptive image alt text and helpful internal links.

Technical basics

Make sure pages load quickly, work on mobile and can be crawled. Google Search Console is a free official tool for spotting issues.

Checklist

  • List your main services and search phrases
  • Map one main phrase per page
  • Write unique titles and descriptions
  • Check mobile usability and speed
  • Set up Search Console
